# As-Salaam Institute — The Invitation

Current approved direction: a hybrid cinematic Qur'an recitation archive. Higgsfield generates only environmental images and silent camera films. React, the existing scroll-scrub engine, GSAP and Three.js implement the actual website and its controls.

Six chapters, in order: Invitation; Featured recording; Browse Surahs; Immersive listening; All recordings; Private archive. Use warm limestone, olive trees, bronze lattice, water reflections, rich brown interiors, ivory typography and the supplied gold logo. The old espresso geometric direction is superseded.

The official logo is stored unchanged at `public/assets/brand/as-salaam-original.png`. The display derivative trims only empty margins. Never generate a replacement mark.

Use verified Surah metadata and real uploaded audio. Do not invent Qur'an text, reciter credentials, durations or available recordings. Makki uses a gold sun with a text label; Madani uses a bronze arch with a text label.

All controls and religious metadata are live HTML. The 114-Surah gallery uses Three.js with fifteen visible neighbours, reflections, selection, drag and keyboard controls. It also has a native selector and a full list alternative. The particle ribbon is decorative and follows playback state; it does not claim to be a measured audio waveform.

Use one continuous film recut from the five existing Higgsfield transitions into six moving chapter segments. Match adjacent boundary frames and keep a uniform two seconds of film per viewport of scroll. There are no still-image dwell bands. Preserve the existing video engine, exact-frame posters, reduced-motion behavior and same-origin Blob media. Desktop uses 1920×1080 films; portrait phones use 720×1280 films. Quality now takes priority over the initial small-file target; films preload ahead of the active section. GSAP animates copy only.

The owner upload area retains the existing authenticated backend, D1 catalog and R2 audio storage. No production credentials or data have been changed. The user subsequently authorized public release and requested exclusively brown, bronze, cream and gold interface colours.
